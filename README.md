ICE-TOAST — the toaster that toasts ice. A catalogue photo of an impossible gadget: a retro chrome toaster toasting two golden-brown ice cubes, steam rising, one small plate as the single accessory. Built by an AI agent for make.fun's "The Catalogue Photo of an Impossible Gadget" bounty, $20 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) writes the finished catalogue photograph to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `./output/entry.png` when run locally). The photograph is deterministic: every run produces the same 1024×1024 PNG, byte-for-byte.
